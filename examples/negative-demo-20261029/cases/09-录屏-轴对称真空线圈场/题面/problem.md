# Pleiades WHAM 真空场示例：平衡迭代起点

本题计算一个已给定参数版本的 Pleiades/WHAM 轴对称真空线圈场示例。它是后续平衡迭代的真空场/初始场输入，不是完整等离子体平衡求解，也不声称已经完成压力、等离子体电流、自洽边界或稳定性计算。

读取 inputs.json 中已经完全展开的 84 个等效单匝圆环和 R-Z 网格，使用公开 SciRel 圆环真空场能力完成场评估，再由显式 glue 生成场数组、轴线/中面剖面、镜像比和运行回执。

R、Z 单位 m，电流 A，B 单位 T，psi=R A_phi 单位 Wb/rad；不得再次乘绕组或群组数。结果可作为平衡迭代的起点/边界输入，不能被包装成“完成了一次平衡”。
