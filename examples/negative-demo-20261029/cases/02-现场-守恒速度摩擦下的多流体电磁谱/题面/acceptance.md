# 公开判定与候选边界

完整覆盖每个公开碰撞工况和k。每谱恰有4S+6个有限复频率，一一匹配并保留重复根、零根与负频根；不要求来源排序。两项增长诊断必须与本谱自洽，谱和须与公开3 trace(nu)恒等式相容。必须能区分输入转置、对角项符号错误、遗漏耦合、零化非零矩阵、只返回正频和删除重根等会改变输出的错误。物种重排须同时重排nu的两个轴，物理谱应等价。

仅凭有限公开输入不能证明通用求解器，也不能排除一个完全复制全部参考数值的硬编码答案；隐藏数值工况和独立科学审阅另行准备。数学上恰好保持全部本征根的变换不能仅由全谱比较器拒绝。
