# 固定轮廓、掩膜与九项几何观测

## 1. 纯数据输入与固定边界

全部长度为m。原六个轮廓参数和theta范围以inputs.json的fixed_inputs为准，逐项保持。新选参数只在selected_finite_input中。十进制标量先nearest binary64、ties-to-even取值；构造表达式用这些常量的实数值，写入每个顶点坐标时单次舍入为binary64。不要求不同科学实现逐位输出相同，不新增误差预算。

令theta0、theta1为原theta_range_rad两端，theta_k=theta0+(theta1-theta0)k/256，k=0…255。用原R(theta)、Z(theta)表达式计算各点；末点P_256精确复制P_0，不能独立重算theta1处三角函数再假定逐位闭合。core_boundary按[point,coordinate]存储，shape=[257,2]，列为[R,Z]。不改变点序，不排序，不重采样、滤波或自动插入点。

上述点列就是此有限题供给的闭合边界；不需要磁通网格、临界点或GS解来再生成一条边界。本题没有声明任何更广泛的平衡存在性、磁场或限器物理结论。

## 2. 完整体积网格、dR/dZ与limiter_core_mask

体积数组的轴序明确为[R,Z]，第一轴径向、第二轴竖向：
R_i=RN64(Rmin+(Rmax-Rmin)i/64)，i=0…64，
Z_j=RN64(Zmin+(Zmax-Zmin)j/128)，j=0…128，
其中Rmin=0.8m、Rmax=2.4m、Zmin=-1.1m、Zmax=1.3m，括号内按固定binary64常量的实数值计算后一次舍入。R_grid[i,j]=R_i，Z_grid[i,j]=Z_j，两者shape=[65,129]。dR=RN64(R_1-R_0)，dZ=RN64(Z_1-Z_0)，它们是源节点状态的首相邻差，不另换成单元中心间距、局部非均匀间距或面元面积。

每个网格节点Q=(r,z)的掩膜M[i,j]按同一存储多边形定义，无需外部档案。对256条有向边A=P_k、B=P_(k+1)，用已舍入顶点和网格坐标的精确实数值做以下判断：

1. 若 (r-A_R)(B_Z-A_Z)-(z-A_Z)(B_R-A_R)=0，且r、z分别位于边两端对应坐标的闭区间，则Q属于边界，M=1。
2. 对非边界Q，只考虑 (A_Z>z) 与 (B_Z>z) 真值不同的边。对每条这样的边计算 r_cross=A_R+(z-A_Z)(B_R-A_R)/(B_Z-A_Z)；当 r<r_cross 时计一次穿越。水平边不满足该跨越条件，不做除零。
3. 穿越数为奇数时M=1，否则M=0。先做边界判断，所以顶点/边节点归属确定；跨越条件中的严格>形成半开端点规则，避免顶点重复计数。

该掩膜是本批按同一有限outline新构造的输入，不声称已经由GS求解、核心掩膜算法或任何来源运行产生。掩膜shape=[65,129]，值为0或1；不加epsilon、不调用隐藏点包含库、不按另一条平滑边界生成掩膜。选定网格覆盖原形状：由|R-R0|<=a、|Z-Z0|<=b(1+|eta|)可作直接范围检查，无需算九个观测值。它是一组合法的离散几何输入，不声称来自已经收敛的GS解。

## 3. 有限面积、周长和源式网格体积

记P_k=(R_k,Z_k)，k=0…256，最后点已闭合。平面无符号面积和极向周长为
area_m2=abs(sum_(k=0)^255(R_k Z_(k+1)-R_(k+1) Z_k))/2，
perimeter_m=sum_(k=0)^255 hypot(R_(k+1)-R_k,Z_(k+1)-Z_k)。
这是无孔闭合多边形面积和直线段长度，不是连续参数曲线的高阶积分或解析周长。面积单位m²，周长单位m。

体积严格取
volume_m3=2pi sum_(i=0)^64 sum_(j=0)^128 R_grid[i,j] dR dZ M[i,j]，
pi为binary64常数0x1.921fb54442d18p+1，求和数学顺序为i外j内。整个节点阵列参加求和，每个节点的面积权都为完整dR*dZ，包括矩形边缘；M是上一节的limiter_core_mask。

这个体积是掩膜节点矩形和。不能用2pi乘多边形径向质心与面积、解析体积、连续积分或截面积对应的另一个离散权重替代。多边形area/perimeter与网格volume使用两种明确的有限表示，不能在没有新科学判断时强迫二者满足精确连续关系。这里只规定数学有限和，不声称复现某个NumPy版本的内部归约位序或已接受跨网格误差。

## 4. 顶点极值、相等值取舍和六项形状标量

所有极值只在core_boundary的257个实际顶点中取，包含闭合重复点。不沿边插值，不从连续outline求最优点。输入顺序从0扫描，只有严格更小/更大才替换极值索引；相等值保留首次出现的顶点，与一维首索引argmin/argmax语义一致。

令Rmin、Rmax、Zmin、Zmax是顶点极值，j_top为首次Zmax索引，j_bottom为首次Zmin索引，R_top=R[j_top]、R_bottom=R[j_bottom]。然后
Rgeo_m=(Rmax+Rmin)/2，
Zgeo_m=(Zmax+Zmin)/2，
minor_radius_m=(Rmax-Rmin)/2，
elongation=(Zmax-Zmin)/(Rmax-Rmin)，
triangularity_upper=(Rgeo_m-R_top)/minor_radius_m，
triangularity_lower=(Rgeo_m-R_bottom)/minor_radius_m。
几何中心不是顶点平均、磁轴或电流中心；上下三角形度不交换、不取绝对值，不用delta参数直接填值。上述前三项单位m，后三项无量纲。

## 5. 状态、失败与范围

输入已经是供给上述有限算子的纯数据状态。体积所需R/Z/dR/dZ/limiter_core_mask完整，形状所需core_boundary完整；没有必要要求先求一个equilibrium对象或验证GS收敛。本页不声称特定高层入口已经被适配成直接接收outline，也不因其包装调用存在就将题意重新列为阻塞。

本次选定数据有正R、正网格步长、完整闭合轮廓和非退化宽高。若将来实际输入装载失败、数组形状/掩膜轴序错误、掩膜不是0/1、坐标/结果非有限、轮廓未闭合或退化到形状分母为零，应明确失败，不能用零/解析形状参数/旧结果补齐；不能把缺失mask当全1。来源在缺少mask属性时会抛出属性错误，本文通过供齐数据解决缺项，不修改这个行为或伪造求解记录。多边形的面积/长度与极值表达式没有新增隐藏裁剪或容差；非法输入时不声称来源原本已有额外防护。

九个请求结果都应是有限标量。当前不执行构造、网格求和、多边形度量、源函数或比较器，也不填入任何结果值。数值比较预算、物理适用性与人工科学接受仍另行pending；它们不是普通输入缺口。squareness、依赖Jtor的电流中心、完整FGN-GEOM其它分支不在这九输出中，本卡不自动取得其覆盖信用。
