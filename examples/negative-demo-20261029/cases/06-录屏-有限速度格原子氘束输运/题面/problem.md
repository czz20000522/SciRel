# 有限速度格上原子氘束的电离与电荷交换输运

本题只考察 `inputs.json` 固定的原子 slab、简化质子电荷交换和有限代次；默认 ADAS、分子耦合和更宽碰撞族属于题外范围。所需速率函数、网格和边界规则必须由公开输入与公开 SciRel 叶子显式提供。

SciRel 公共能力边界：`scirel.kinetic.solve_atomic_slab_transport` 负责公开的有限速度 slab 求解。题目专属报告、展示和输出封装属于 agent glue。运行环境必须安装随包提供的 SciRel wheel；没有该公开 wheel 时应报告 `HOLD_PUBLIC_RUNTIME_MISSING`，不能用局部速率或另一套实现冒充本题结果。

入口输入是正向入射密度，不能直接把它当作入口总密度。边界分布归一化后，入口总密度应由正向与负向速度分布的非负积分相加得到；若输出是派生网格上的第一个节点，必须明确记录该网格和边界含义。

达到 `max_generations` 而未满足 `delta_g < 0.001` 时，已有有限分布可以作为诊断结果保存，但状态必须是 `HOLD_GENERATIONS`，不能包装成正常完成。

输出必须保留实际求解网格、速度轴、分布、边界分布（若公开 API 返回）、密度/通量/温度/能流/源项以及代次诊断；任何公开 API 未提供的字段必须列入 `missing_outputs`，不能用零、形状或插值假装补齐。
