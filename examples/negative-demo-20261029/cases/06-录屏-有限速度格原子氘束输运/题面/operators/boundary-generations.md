# 入口、代次输运、输出与失败规则

## 单位、轴和任务范围

一维空间 x 用m；轴对称速度坐标 r=v_perp/vt>0、u=vx/vt可正可负，均无量纲，vt=sqrt(2e*Tnorm/(mu*mH))，mH=1.6726231e-27 kg、e=1.602177e-19 C，mu=1或2。三维数组轴固定为 [radial_velocity,axial_velocity,space]；速度积分权 w_ij=radial_volume_i*axial_width_j，定义见网格说明。n=sum(w*f)的单位为m^-3，所以f为对无量纲速度体积的数密度，不是直接对物理(m/s)^3的相空间密度；物理速度分布要另除vt^3。

当前固定题是独立原子输运：mu=2，既定解析电离/复合与简化质子CX，弹性/分子相互作用均关闭；显式输入原子源fSH为0（复合源仍启用）、分子分布和分子离子密度为0，管径0。它是原模型已有显式配置，不是完整原子所有碰撞开关、分子输运或原子分子耦合问题的替身。它没有把默认表模型替换成新拟合；其它原模型分支的定义及资产边界单列。

## 1. 入射密度与通量的两个层次

底层接收边界形状 B(r,u)，只保留u>0，u<0全置0。令 Gamma_B=vt*sum_{u>0} w*u*B。若指定通量G的绝对值>0，则将B乘abs(G)/Gamma_B；若G=0，则直接得到零入射。G即使为负也取绝对值，不能理解为从右侧注入。非零G配合零/非有限Gamma_B没有合法有限归一化；应报告HOLD，不造分布或悄悄更换G。

上层的incident_density是入射那一半分布的密度，并非含反射的总边界密度，也不是单位m^-2 s^-1的通量。固定题用若干正向单能组分，密度份额a_l（sum a_l=1）、物理正速度v_l=sqrt(2e E_l/(mu mH))。在已生成速度节点中，选择使abs(u_j-v_l/vt)最小的j，平局选最早下标；放到最小径向节点i=0：

    B[0,j] += a_l*incident_density / w[0,j]
    G += a_l*incident_density*v_l

随后仍执行底层通量归一化。因节点速度与组分速度、最小径向节点与真实零径向速度有有限差异，最终边界密度不必再精确等于incident_density；不能反过来改G或再次按密度归一化。

原上层另有任意入射分布分支：将物理速度网格数据在端点夹边后，对log(max(B,tiny64))作张量三次插值（两轴阶数3）；指数还原并裁为非负，再令负向节点为0，按入射密度归一化，然后计算G=vt*sum w*u*B。该分支要求两条输入物理速度轴严格递增、至少各4个节点，数据为对应二维形状，tiny64为最小正规正binary64数；张量三次插值采用插值B样条（平滑因子0）。它不参与当前固定单能题，也不作为本题已交付的任意分布条件。不能将它与底层“任意B但以G为权威”的约定混为一谈。

左边x[0]是正向入射。固定题右边x[-1]没有负向外部入射，真空流入值为0；左边负向出射由输运求出。它不是反射边界或周期闭合轨道。速度边缘没有额外流入/尾部补偿：所有速度积分严格用给定有限格。

## 2. 初始化与原空间推进

在新建求解上下文中，初始原子分布、分子分布、分子离子密度和显式原子源全为0，分子离子温度为1eV。将左端正向分布置为归一化B；分子分布和0使原子–分子弹性开关关闭。电子密度经准中性修正ni=max(ne-n_molecular_ion,0.01*ne)；原过程即使关闭修正也施加0.01*ne下限。本题n_molecular_ion=0，故ni=ne。

碰撞说明给出无量纲速度和m^-1量纲的损失a(r,u,x)、原子生成源S(r,u,x)，以及由上一代得到的CX源beta。空间每格dx=x[k+1]-x[k]。正向u>0：

    denp = 2*u + dx*a[k+1]
    A[k] = (2*u-dx*a[k])/denp
    Bcoef[k] = dx/denp
    F[k] = Bcoef[k]*(S[k+1]+S[k])

负向u<0反向推进：

    denn = -2*u + dx*a[k-1]       # dx=x[k]-x[k-1], k从右向左
    C[k] = (-2*u-dx*a[k])/denn
    Dcoef[k] = dx/denn
    Gsrc[k] = Dcoef[k]*(S[k-1]+S[k])

同一式对每个径向节点独立。不能把它替为解析指数衰减、上风格式或新ODE求解器。网格稳定性先检查：各空间节点，取全部u>0与径向格中有限且>0的2*u/a最小值，无候选则默认1e32；每段允许步长为左右节点阈值最小值。若dx大于允许步长，来源明确抛出“空间步长过大”；本题报告HOLD，不自动细化再算。

第0代：左端正向B，右端负向0；正向按f0[k+1]=A[k]*f0[k]+F[k]，负向按f0[k-1]=C[k]*f0[k]+Gsrc[k]。随后n0[k]=sum w*f0[k]。总分布初始化为f0，总密度为n0。

第g>=1代：以刚完成的上一代fg-1构造beta及弹性生成M（本题M=0），新代数组全置0，故两端外部流入为0。依次推进

    fg[k+1] = A[k]*fg[k] + Bcoef[k]*(beta[k+1]+beta[k]+OmegaM[k+1]+OmegaM[k])
    fg[k-1] = C[k]*fg[k] + Dcoef[k]*(beta[k-1]+beta[k]+OmegaM[k-1]+OmegaM[k])

正向式只用于u>0，负向只用于u<0。ng=sum w*fg；先将fg与ng加入总分布/密度，再判断截断。不可在一代开始时把正向B重新注入每代。

## 3. 截断与外层迭代

第g代密度贡献准则为delta_g=max_k(ng[k]/max_k n_total[k])。本题当delta_g<truncate时停止，严格小于；本题truncate=1e-3，max_gen=50。停止前已累加此代。循环顶部先判断g>=max_gen，未达到截断而进入此分支就抛出未收敛，不将已计算50代当正常通过。若该代刚好达到50并已满足截断，可正常退出；不以模型推测强行加代或降低阈值。

本题电荷交换开、所有弹性关，所以有代次生成但无弹性外层自洽迭代。一般原模型只要任一H–H、H–P、H–H2弹性开，就有外层：以上一次总f、n冻结本轮碰撞频率，重复第0代和散射代；每代弹性目标仍由该代前一代分布和密度重新构造，不在外层整轮冻结。外层误差delta_seed=max(abs(n_before-n_after))/max(n_after)，<=10*truncate时退出；代内可提前在delta_g<0.003*delta_seed时截断。原过程没有单独外层次数上限；完整弹性任务不能私加上限并称原模型同一解。零分母、非有限或不收敛需明确HOLD。

结束后还用最后一代补一次beta与各弹性目标累计项，供源/能量/动量诊断；不能遗漏，因为输运停止不代表最后一代不发生损失。

## 4. 输出定义

令W(X)=sum_{i,j}w_ij X_ij，vbar=Gamma/n/vt，c2=r²+(u-vbar)²。以下对每个空间节点输出，不对空间再作隐藏积分：

    n = W(f)                                      [m^-3]
    Gamma = vt*W(u*f)                             [m^-2 s^-1]
    V = Gamma/n                                  [m/s]
    p = mu*mH*vt²/(3e)*W(c2*f)                    [eV m^-3]
    T = p/n                                      [eV]
    pi_xx = mu*mH*vt²/e*W((u-vbar)²*f)-p           [eV m^-3]
    q_random = mu*mH*vt³/2*W(c2*(u-vbar)*f)        [W/m²]
    q_total = (mu*mH*n*V²/2+2.5*e*p)*V + e*pi_xx*V + q_random  [W/m²]

输入/输出总密度不裁成入射密度。温度/流速等除以n，n=0或非有限不是定义为0的理由。

令C=vt*(S+beta_sum-a*f+sum_elastic Omega*sum_generational M)，这是诊断使用的离散碰撞源（m^-3s^-1/无量纲速度体积）。本题最后一项为0。输出

    Sion = vt*n*alpha_ion                         [m^-3s^-1]
    Snet = W(C)                                  [m^-3s^-1]
    Qthermal = mu*mH*vt²/2*W(c2*C)                [W/m³]
    Rx = mu*mH*vt*W((u-vbar)*C)                   [N/m³]
    Qtotal = Qthermal+Rx*V+mu*mH*Snet*V²/2         [W/m³]

源代码的部分注释把p或Rx写成错误的空间量纲，题面以以上公式单位为准，不对值增加长度因子。原SideWall诊断为W(gamma_wall*f)，没有乘vt，故按其算子本身单位是m^-4；当前PipeDia全0，此项精确为0。不要用修正单位的名义把它改成新算法。若扩展非零管径，还必须解决碰撞说明所列广播依赖；本题关闭该分支。

左边反照率为-Gamma_minus/Gamma_plus，Gamma_plus=vt*sum_{u>0}w*u*f(x0)、Gamma_minus=vt*sum_{u<0}w*u*f(x0)；Gamma_plus为0时原规则取0。并保留输入边界B、所用G、速度节点/Tnorm、网格和第0代/各代密度（若要求）。代密度数组只到实际停止的最后代，不用未计算的全零列填满50代；完整f只取最后外层总和，不将历史外层再次相加。

## 5. 公开失败、参考与科学判断

先拒绝非有限输入、长度/形状不符、非增空间轴、非正径向节点、含0或不成正负镜像的轴向节点、非H/D质量标记及未定义的边界归一化。来源有明确输入异常的，保留失败信息和阶段；其它出现非有限、零分母、核/补偿没有合法输出或生成代数不收敛时报告HOLD，不裁掉负值或换拟合凑结果。这里的fail-closed报告是交付判定，不能被表述为给原程序打补丁。
