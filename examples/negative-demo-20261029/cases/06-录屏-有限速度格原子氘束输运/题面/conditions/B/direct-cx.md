# B：保留单能入口的直接电荷交换条件

本条件属于同一题根/id `kn-atomic-slab-analytic-cx`，是**静态条件候选，主审pending**。
唯一配置变动是 `configuration.collisions.SIMPLE_CX=false`。它独立从
[原inputs.json](../../inputs.json)实例化；没有串联任意入口条件A。
原50点背景、mu=2、vxi=0、3eV单能入射/密度1e15 m^-3、mesh_size=6、grid_fctr=.3、
解析电子电离/复合、H_P_CX=true、所有弹性false、复合和离子修正true、管径0、
原常数、全零分布/分子密度种子、分子离子温度1eV、truncate=.001、max_generations=50、
fresh_context及诊断关闭等均取原值。保持原[输出规范](../../output-spec.json)。

## 1. 同根依赖与精确覆盖范围

完整[网格、有限格与离散Maxwell](../../operators/mesh-projection.md)、
[电子率与一般碰撞框架](../../operators/collisions.md)、
[单能入口、空间推进、代次、输出与失败](../../operators/boundary-generations.md)仍适用。
本文件把这些基准文件中“当前有限题启用简化/Maxwellian-weighted CX”的实例描述，
仅对B条件实例化为下面的直接碰撞积分：替换全部活跃 `alpha_cx`、`beta_cx` 计算；
相应总损失、代次和输出中的这些符号取本文件定义。
“其它CX分支不参与固定题”的描述继续属于原基准；B明确激活本节直接分支。
原输入的3eV分量和E0=[3]不改，不能使用A的任意入口数组、额外能量或密度归一化。

网格构造规则也不切换：其细格反应频率估计仍使用原碰撞文件中已完整给出的
Maxwellian-weighted解析 `C(T_i,E_min)`；它是原建网启发式输入，不是B求解器的直接CX损失。
`SIMPLE_CX`不作为网格构造器输入。按原50点剖面、原E0和原两次建网配方独立生成网格；
这里没有给出或计算固定求解网格、Tnorm、核、率或答案。

## 2. 速度、质量、权重和背景离子

沿用基准符号，`m0=1.6726231e-27 kg`、`e=1.602177e-19 J/eV`、`m=mu*m0`、
`v0=sqrt(2*e*Tnorm/(mu*m0))`。节点`r_i>0,u_j`无量纲，物理速度是`v0*r_i,v0*u_j`；
轴序为`(radial,axial,space)`。空间位置记k。有限格权重

`R_i=pi*(r_right_i^2-r_left_i^2)`、`d_j=u_right_j-u_left_j`、`w_ij=R_i*d_j`，
`W_k[g]=sum_ij w_ij*g_ijk`。

边界微元由共同网格文件定义，不能换成点值`2*pi*r*dr*du`。
离子单位密度分布`F_i[:,:,k]`是同根完整补偿Maxwell在本条件网格、`Ti[k]`、
物理`U_i[k]=vxi[k]`、mu和粒子倍数1下的结果；`W[F_i]=1`是其归一化约定。
没有重新以简单连续Maxwell代换，或因为补偿后某元素不正而自行裁剪。
离子密度按原式 `ni=max(ne-nHP,.01*ne)`；这里nHP全0，故ni=ne。

## 3. 实际选定截面：Janev九系数

所选直接积分实际调用截面时未指定Freeman选项；其默认false，因此本条件明确使用
下列Janev原子电荷交换多项式。Freeman公式不参与本条件。
输入E为以氢参考质量表示的质子–中性原子相对能量eV。令

`Ec=clip(E,0.1,2.01e4)`，`z=ln(Ec)`，
`P(z;c)=c0+z*(c1+z*(...+z*c8))`，
` sigma_CX(E)=1e-4*exp(P(z;c)) `，单位m^2。

```text
c = [-3.274123792568e1, -8.916456579806e-2, -3.016990732025e-2,
      9.205482406462e-3, 2.400266568315e-3, -1.927122311323e-3,
      3.654750340106e-4, -2.788866460622e-5, 7.422296363524e-7]
```

系数按升幂给出，Horner从最高阶向最低阶运算；log为自然对数。
0.1和20100 eV是实际夹取端点，不是反应阈值：域外按端值拟合，
不在低能区额外返回0，不把上界改成20000，不增加截面或能量平滑。
1e-4只做截面cm^2到m^2的原转换；这里不是m^3/s速率，不再乘1e-6。
部分历史说明将截面单位写成逆面积，实际公式所用的是面积m^2。
科学引用：R. K. Janev等，Elementary Processes in Hydrogen–Helium Plasmas，1987，p.250。

## 4. 成对速度核的完整离散定义

令输出速度单元`p=(i,j)`、被积分速度单元`q=(a,b)`。
使用五个中点角度 `theta_l=pi*(l+.5)/5`，l=0..4，各角权重1/5。
对每个角计算

```
radial2_pql = r_i^2+r_a^2-2*r_i*r_a*cos(theta_l)
g2_pql     = radial2_pql+(u_j-u_b)^2
g_pql      = sqrt(g2_pql)
E_pql      = m0*v0^2*g2_pql/(2*e)
```

这里E的质量因子是m0，不是mu*m0。等价符号式为
`E_pql=(Tnorm/mu)*g2_pql`，不先使用Ti/mu或截取某单个入射能量。
mu已经影响v0和背景Maxwell，不再额外缩放截面或整个核。
能量E先传入上一节截面，截面内部夹到[.1,2.01e4]；
`g`仍取未夹取的相对速度。不得用夹取能量反算g。
构造g之前没有`max(g2,0)`补丁；非有限/非法平方根按原算术传播或失败。

定义角平均及矩阵

`L_pq=(1/5)*sum_l g_pql*sigma_CX(E_pql)`，
`K_pq=w_ab*L_pq`。

K的量纲为m^2，角平均没有额外2*pi、v0、mu或1/v0；
径向积分的2*pi已经在`R_a=pi*(r_right_a^2-r_left_a^2)`中。
每个相对速度项独立求截面再求角和，不能先平均能量或速度再取截面。
该核在生成网格之后、按静态数据一次建立，并对所有空间位置共用。

矩阵存储精确采用径向快索引：
`p=i+Nr*j`、`q=a+Nr*b`，
`vec_F(g)[i+Nr*j]=g[i,j]`。
源实现先将角张量按Fortran次序展成`[(Nr*Nu)^2,5]`，
乘五角权重列后，恢复`[Nr,Nu,Nr,Nu]`、乘被积分单元权重，再展成
`[Nr*Nu,Nr*Nu]`；上面的K正是这个结果。
恢复二维分布也用`unvec_F`。不能用axial快轴或转置K替代。

## 5. 直接损失与每代出生分布

对每个空间点k，首先计算

`alpha_cx[:,:,k] = unvec_F(K @ vec_F(ni[k]*F_i[:,:,k]))`。

它的单位为m^-1。没有再除v0，因为K内相对速度g已经除过v0。
也不从原81系数Maxwellian-weighted率取得活跃损失。
对任意一个输入代分布g，出生项为

`beta_cx[g][:,:,k] = ni[k]*F_i[:,:,k]*unvec_F(K @ vec_F(g[:,:,k]))`。

这是逐速度点乘积，单位m^-4，即分布每单位空间长度；物理碰撞项为v0倍。
不能改成简化式`F_i*W(alpha_cx*g)`，不能把K作用于`ni*F_i*g`，
不能用背景离子温度给某一平均速率，也不重新归一化出生项以消除一个计算出来的残差。
新生原子的速度依赖`F_i[p]`及该输出速度与全部旧原子速度的成对积分。

其余电子项仍完全沿用原解析模型：
`alpha_ion=ne*K_ion(Te)/v0`，
`S=F_i*ni*ne*K_rec(Te)/v0`，显式原子源为0。
本条件的总损失仅为

`alpha_total=alpha_ion+alpha_cx`，

因为所有弹性频率和管壁项为0。不能因B激活全CX积分而开启弹性外层自洽。

## 6. 构造、缓存、代次和输出顺序

构造先执行原速度微元与单能边界缩放，建立共同状态，再执行原构造检查；
静态阶段按原顺序建立速度平方/相对背景能量、离子Maxwell、解析电子率、
成对相对速度张量及K，然后继续原有弹性核静态预计算（即使弹性关闭）。
后者沿用共同文件的非活跃定义，未因B另改。原静态`Ti/mu`和单速度
`ErelH_P=clip(m0*v0^2*(r^2+(u-U_i/v0)^2)/(2*e),.1,2.0e4)`仍会建立，
但它们不进入本条件第5节直接alpha/beta；其原用途不能误移到直接核能量。

在本条件fresh实例首次调用中，先做原运行输入形状检查；将分子弹性flag恢复后
按零fH2关闭；再就地覆盖种子左正向边界。动态缓存判断要求逐项完全相等，NaN不相等。
初始缓存均缺失，所以New_Molecular_Ions=true，原ni与S先计算，随后按本文件计算alpha_cx。
一般原缓存门控是`(alpha_cx is None or New_Molecular_Ions) and H_P_CX`；
B不新增“因为中性分布变化而重算alpha”的门控。alpha取背景离子，
beta则在每代对该代分布重新计算。完成全部输运、输出编译及所选诊断后才保存输入引用，不跨A/B共享实例。

接着按原式计算种子密度、零管壁项、全零弹性频率和alpha_total，
先执行原空间步长检查，才生成输运系数和第0代。检查对每位置所有正u及径向点的
`2*u/alpha_total`只保留有限正值取最小，无候选保留1e32；
每段阈值取相邻两点最小值，若dx大于阈值则原“空间步长过大”失败。
不能按新的直接CX频率偷偷重建/细化原空间网格来使检查通过。

H_P_CX仍true，所以原碰撞代循环仍开启。第g>=1代先以刚完成的旧代计算上述beta，
加到beta_sum，再按原空间推进方程生成新代；先累加新代，再判断
`delta_g=max(n_g/max(n_total))<.001`，严格小于。
循环顶部仍按原`g>=50`抛未收敛；不能增加代数或放宽阈值。
所有弹性关闭，因此原fH_iterate=false，完成这一组第0代/散射代后退出外层。
离开后仍用最后一代再补一次beta_sum，只补出生累积，不再推进一代。

原[输出定义](../../operators/boundary-generations.md)和[输出spec](../../output-spec.json)不变。
其中物理诊断碰撞分布使用
`C=v0*(S+beta_sum-alpha_total*f)`；密度/通量/温度/能流/净源/电离/动量与总能量等矩
仍按原有限格权重计算。若查看原持久CX内部量，其
`C_CX=v0*(beta_sum-alpha_cx*f)`，动量用`m*v0*W((u-U/v0)*C_CX)`，
总能矩用`.5*m*v0^2*W((r^2+u^2)*C_CX)`；这不新增强制输出或残差阈值。
ci_test=false、alpha_cx_test=false、compute_errors=false，
故不执行额外率比较/碰撞积分诊断；空间步长检查不受此诊断gate影响。

## 7. 失败与静态接受边界

原基准所有输入/构造/运行形状检查、先后次序、零分母、非有限算术、
空间步长与代数失败都保持。对NaN的原比较为false，max/min按NumPy归约传播NaN；
不新增全局finite守卫或“零频率乘NaN变零”的约定。
例如K、alpha、beta、Maxwell补偿或输出矩非有限时，应报告首次实际阶段/索引与最后状态，
不能以另一拟合、追加物理阈值、截负数、改权重、改空间网格或强制全零返回替代。
这些是既有失败与结果报告规则，不是给来源核打修复补丁。

本文件只建立选定B分支的数学/输入闭包；没有构造任何数值网格或核、
计算截面/率/谱线、运行来源/solver/参考/重放。所选输入下是否通过原空间检查、
50代截断以及数值/物理正确性都仍pending。
解析公开输入不需要受限ADAS/PEC值；来源模块的ADAS导入期依赖与未来runtime封装单列，
不能据此给本解析分支补表、换模型或推断已有再分发授权。
