# 抽象磁误差向量的离散电流反馈控制律

对象是给定10维磁测参考向量r与测量向量y所产生的控制电流，不含磁场重建、线圈/等离子体plant、传感器几何或机器校准。r、y和误差e=r−y的每个分量以T计；11维外部前馈及最终输出以A计。10个通道仅按位置编号，不把它们命名为未经给定的具体磁测通道。给定11×10矩阵K定义这个抽象题的映射，其装置适用范围不作承诺。

`model.json`是本题全部数值参数：h=0.001s；P=1、I=0、D=1s、N=100/s（各10项）；K=`coefficient_matrix_unscaled`×`coefficient_scale`，在本题单位约定下为A/T。这里给D/I/N标注的是使本题量纲闭合的控制律单位，不声称原输入bus逐项声明过这些单位。不要使用另一个旧总参数表中的D=0，也不要将输出解释成电压。

每个使能采样点，令a_j为积分状态、z_j为D滤波状态，均是本步输出前状态。计算p_j=P_j e_j，i_j=a_j，d_j=D_j N_j(e_j−z_j)，c_j=p_j+i_j+d_j；IC_FB=Kc，u=ExtFF+IC_FB。随后按Forward Euler更新a_j←a_j+h I_j e_j，z_j←z_j+h N_j(e_j−z_j)。30维内部输出顺序为[p1,i1,d1,p2,i2,d2,…,p10,i10,d10]。I=0时积分项恒零仍应保留其状态/输出槽。

全新运行的a、z均为0；内部积分使能恒为10个1，内部独立reset恒0。外部enable仅取0或1。enable=0时整个PID子系统停止更新，PID内部输出和反馈电流保持先前输出，最终u绕过反馈直接取ExtFF；误差e仍随r、y计算。enable从0变1时，先将a、z重置到0，再按当前输入计算输出和本步状态更新。初始enable=1同样从全新零状态开始。不能以“禁用即把所有输出设0”或“重新使能继续旧滤波状态”代替此规则。

本题明确采用4个根输入端口h=1ms、offset=0、Interpolate=off的I/O绑定。所有输入在`input_time_s`的采样时刻更新，右连续零阶保持到下一点；最终点保持至停止时刻。原状态块的Forward Euler、InitialConditionSetting=Auto、零初态与reset/held设置保持；该边界绑定将原本继承的根端口采样具体化，不声称原封不动的任意继承采样场景与本题相同。

原生仿真协议仍使用活动configurationSettings引用及所提供的VariableStepAuto、auto步长、RelTol=1e-3、AbsTol=auto、LoadInitialState=off；不改成固定步求解器。任务只把运行窗口从模板默认时长改为0–0.12s并请求全部1ms观察时刻。观察请求可能让原生可变步求解器增加major hits；它不是新发明的状态积分算法或科学精度保证。

输入表包含上升、反向误差和独立前馈变化，并在40–54ms与95–104ms禁用，在55ms与105ms重新使能。数组中的数值是权威输入，不从描述再生成一套不同波形。输出必须覆盖所有观察点，不漏通道，使用每个精确观察时刻最后一个原生记录；缺失观察点不得用未披露插值补齐。
