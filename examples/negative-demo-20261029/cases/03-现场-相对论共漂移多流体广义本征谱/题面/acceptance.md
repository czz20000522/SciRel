# 公开判定及当前候选边界

输入工况和species必须完整。全谱每个k恰有4S+6个复频率，编码[实部,虚部]，包括零根、重复根和负频根；不允许只给正频分支或按增长率裁剪。模态集合匹配必须一一对应并保留重数，不要求来源排序。稳定性按Im(omega)符号解释，不输出其绝对值替代。

所有输出应有限，违反输入约束时明确失败。极化题允许整体复相位/尺度自由度，按本题输出规格归一化；退化时不得任意挑一个方向冒充唯一极化。

物理数值验收预算尚待指定人工审阅。预算应在待验解出现前由原始精度/离散收敛或独立科学依据决定，不能事后放宽。本文件仅定义公开判定目标，不能作为科学PASS或自动评分已可用的声明。人工科学接受pending。
