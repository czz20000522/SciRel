# 平台科学任务验收

这些是平台内部可重跑的验收任务。终端用户只提出需求，不需要知道包名或安装命令。

| 用户需求 | 交付结果 | 验收依据 |
|---|---|---|
| 比较三个励磁电流在三个探针位置的磁场，并导出表格 | coil_current_scan.csv，9 行，带 A/m/T 单位 | 轴上双环解析场、磁场随电流线性缩放 |
| 用反向双线圈建立测量预测，判断已知测量偏差大小 | 磁通预测、归一化残差和 chi² | 反对称轴向场、中心零点、预设 [1,-2,3] 个 sigma 偏差对应 chi²=14 |
| 检查输入能否求解，避免把不成立结果当作成功 | 明确拒绝单侧真空、重复磁场节点；接受有效等离子体与双侧真空 | 不允许残差1仍返回求解成功，不允许 NaN 节点被忽略 |

`user_acceptance.py` 是维护者验收入口，要求能力已预装在 `/opt/scirel` 的隔离 runtime。
验收启动时不安装任何包；只挂载脚本、只读 wheel（核对安装来源）和结果目录，禁用网络，不挂载库源码。
平台镜像构建先完成 wheel 安装；命令参数为 `--wheel <只读核验归档> --output <结果目录>`。

输出 `acceptance.json` 包含开发 wheel 摘要、实际模块根、正文比对数量和三个任务的判据。
该技术验收不代表来源资产已经正式准入，尤其带科学行为修复的组合必须使用重审后的版本。
