# 磁通坐标剖面与路径采样草稿

状态：**开发期领域索引草稿，待领域专家组织和确认**。本页只记录已实现的关系及适用条件，精确合同见各 exact document。

- [磁通坐标标量剖面](../../catalog/examples/scirel.geometry.flux-surface-profile.json)把配对样本按磁通值排序去重后做一维线性插值；区间外使用首尾样本或调用方显式给出的常值。它不构造空间磁面，也不判断有冲突的重复磁通样本在物理上哪个正确。`psi_samples` 和 `target` 必须使用同一磁通约定。
- [折线一除磁场测度与加权平均](../../catalog/examples/scirel.geometry.flux-surface-inverse-field-average.json)在 R-Z 网格上用三次样条采样正的磁场幅值，沿调用方给定的折线以梯形法计算 `integral(dl/B)`；只有给出 `quantity` 时才返回该量的 `dl/B` 加权平均。它不追踪或闭合场线，返回值仅属于提供的离散路径。

两个算子服务于不同的坐标和计算步骤，没有直接依赖边。已有直接测试覆盖有限样本、端点策略、常场解析退化及部分错误输入；保存的 Pleiades 候选不是当前合格 D1 或专家认可。专家待决：标准磁通归一化、重复磁通样本处置、路径是否应要求闭合与加权平均的物理适用域，以及三次插值的正性/误差边界。
