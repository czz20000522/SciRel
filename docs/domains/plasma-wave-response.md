# 等离子体波响应

状态：能力导航初稿，待领域专家确认分类和典型问题；不代表射频求解或波传播链路已完整。

## 科学问题与输入

现有样例从频率、局部磁场与物种列表计算冷等离子体相对介电张量；另一算子计算已归一化复宗量上的解析等离子体色散函数。输入的坐标基、单位、物种含义、碰撞率、归一化约定以及精确失败条件，应直接查阅各资产文档。

## 开发样例关系与组合

- [局部冷等离子体介电张量](../../catalog/examples/scirel.dielectric.cold-plasma-tensor.json)给出 Stix 冷等离子体响应及其数值证据边界。
- [解析等离子体色散函数](../../catalog/examples/scirel.kinetic.plasma-dispersion-function.json)返回 `w(z)` 与 `Z(z)`；调用方负责频率、波数、漂移和热速度到无量纲 `z` 的映射。它不推断模态或色散根。
- 更大尺度的波传播、边界条件和射频任务图：**未整理**。这一状态不是已核查的能力缺口。

## 证据、限制与待整理项

冷介电张量文档明确排除温/动理学与有限拉莫尔半径修正，也不负责将张量旋转到其他基；返回有限张量不等于为某个实际装置证明模型适用。解析色散函数没有绑定冷张量或任何具体归一化，不能由两者并列推出可直接组合的求解器。领域专家需确定典型问题、模型选择条件和组合验证。相对上一可信版的变化：待建立可信版后填写。
