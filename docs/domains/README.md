# 科学领域能力

这些页面是给专家讨论和修改的**能力导航骨架**，不是完整覆盖声明、审核结论或第二份资产合同。当前链接的 `catalog/examples/` 是 107/114 个 exact document 的开发 pilot，不是可信发布目录。单个能力可以出现在多个领域页；科学身份、输入输出、模型条件、测试和证据上限只在对应的 `scirel.asset-document.v1` exact document 中维护。

阅读领域页时分别记录：**未整理**（尚未完成资产盘点）、**经核查确有缺口**（明确比较范围及证据后确认缺少能力）、**已有但范围有限**（能力存在，模型或适用域不满足更广需求）。不能把缺少目录文档、资产数量少或一次检索无结果直接写成科学缺口。当前 `catalog/examples/` 仅是部分开发期样例。

| 领域页 | 当前开发样例入口 | 专家待定 |
| --- | --- | --- |
| [磁场与线圈](magnetic-field.md) | 轴对称真空场的叶子关系与组合、磁通坐标标量剖面插值 | 领域边界、典型任务与组合证据 |
| [等离子体波响应](plasma-wave-response.md) | 冷介电张量、物种平衡尺度、解析色散函数、Bessel-Gamma 项与有限谐波张量 | 模型、截断与求根任务的边界 |
| [中性粒子输运](neutral-transport.md) | 热速度标度、自适应网格、单代密度与轴对称矩归约、速度积分权重、平移 Maxwellian 种子与两种源/边界归一化 | 完整代际输运链、边界与碰撞模型 |
| [碰撞相关量](collisions.md) | 热电子归一化动量、Maxwellian 相对速度速率平均 | 量纲接线与尚未整理的关系族 |
| [准中性电子闭包](quasineutrality.md) | 镜约束速度矩、参考电子密度、玻尔兹曼电子态与残差、二分电势求解、总压强状态组装及镜面准中性图 | 跨图闭包的状态、坐标和误差边界 |

后续每个领域页可按同一短结构维护：科学问题、必要输入、模型与适用条件、现有资产/TaskGraph、可验证组合、证据上限、限制与缺口、相对上一可信版的变化。上述栏目可以留“待专家整理”，不能凭名称补造科学事实。

## 待专家划界的领域导航

以下是问题导向的检索入口，不是互斥分类，也没有通过项目数或资产数核定覆盖。未列出精确样例的范围仍标记为**未整理**：

- 平衡与磁几何：未整理。
- MHD 稳定性：已有但范围有限；[火蛇与磁镜压强裕度](../../catalog/examples/scirel.diagnostics.firehose-mirror-margins.json)仅计算给定样本的两个判据裕度，完整稳定性能力仍待盘点。
- 色散、波传播与射频：未整理；上表只有局部冷等离子体响应样例。
- 加热与电流驱动：未整理。
- 碰撞与输运：未整理；上表只有少量碰撞相关定义样例。
- 快粒子、聚变源与诊断：未整理。
- 动理学、湍流与 PIC：已有但范围有限；[损失锥角向谱](../../catalog/examples/scirel.kinetic.loss-cone-spectrum.json)、[镜不变量分布](../../catalog/examples/scirel.kinetic.mirror-invariant-distribution.json)及 Frank-Egedal 叶子关系已有 exact document，湍流与 PIC 仍未整理。
- 集成建模与数据互操作：未整理；数据与集成基础设施不直接等于物理算子覆盖。

归档项目目录只提供未来来源线索。纳入能力盘点前须区分相同项目的不同版本、重复来源与真正独立来源；仅列名称、尚待获取源码的条目不能当作已持有 L1 或已有 SciRel 能力。

## 跨领域问题导航

下表是未来组合时需要核对的**概念接线**，不是现成的端到端 TaskGraph。每条连接在建立精确资产、端口和组合证据前都为**未整理**；后续只能在实际检验后改为“已验证有界”或“已确认缺口”，并附比较范围与证据。

| 概念连接 | 首要核对条件 | 当前状态 |
| --- | --- | --- |
| 平衡/磁几何的场与剖面 -> 波、粒子或输运输入 | 坐标与轴序、单位、边界、时间尺度及适用模型 | 未整理 |
| 加热/沉积与粒子源 -> 输运或诊断 | 源项定义、归一化、空间/时间网格、守恒量及证据范围 | 未整理 |
| 稳定性与反馈输出 -> 集成建模 | 状态所有权、反馈顺序、停止条件、时间尺度及失败传播 | 未整理 |

实际可调用连接应落在已验证的 TaskGraph 或明确的调用实例中，并链接相关 exact documents；概念表本身不提供 callable，也不扩大任何资产的科学合同。
