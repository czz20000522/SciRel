# 快离子加热分配：待人工决定的限定增量

本增量评估固定的 Mikkelsen 局部近似关系：x² = E_birth/(10 m_fast T_e)，f_i = 2/x² ∫₀ˣ t/(1+t³)dt。能量和电子温度用 keV，快离子质量用 amu。当前证据支持该数学关系的数值求值；不能据此认可任意等离子体组成、碰撞状态或实验场景的适用性。

冻结 D1 的直接表达式在零出生能量返回非有限值，在极小正能量受相消影响。新实现采用零点连续极限与小 x 级数，在其余数值域保留解析形式。独立验证使用积分换元后的数值积分，覆盖零点、极小量、级数分支两侧、大比值和输入广播；没有放宽原回归断言。有限维度输入仍可能造成无穷比值，接口明确报错。

作者原文把数学连续极限称作物理连续极限，容易扩大证据范围。本后继只更正文档限定；数学实现和原测试不变。作者原 wheel 同时包含其他旧科学模块及开发层，不能作为此项的合格分发；接收端须以精确选择重建并核对实际运行导入闭包。
