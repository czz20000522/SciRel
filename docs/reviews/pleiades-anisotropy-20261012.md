# Pleiades 各向异性与 Hall 闭包：修正后科学审阅

本页对应 `0.2.0.dev4+pleiades.anisotropy` 的所选科学函数。它保留已接收的 Pleiades 几何、电磁场和数值功能，并加入下表的各向异性关系与组合求解。具体参数、单位、边界和异常以相应 exact document 为准。

## 本次需要审阅的科学变化

| 关系 | 修正内容 | 仍需保留的解释边界 |
|---|---|---|
| 轴对称各向异性压力张量与环向电流 | 在轴上采用奇偶正则极限；导数使用局部差分，常量导数精确为零 | 纯极向、光滑轴对称场；不是三维磁流体力学模型 |
| 截面电流与磁通反馈 | 非均匀网格默认在节点张成的域上积分；真实单元中心数据可提供明确边界；同步返回磁通和磁场 | 单元电流为 `J_phi dR dZ`，没有体积因子 `2πR`；调用者提供的 Green 矩阵仍须物理一致 |
| Hall 漂移与迭代 | 按最终状态检查未松弛固定点；保留原容差并在不收敛时失败 | 仍是有限密度、速度上限等假设下的 reduced Hall 模型；速度截断不是额外物理验证 |
| 镜约束分布、俘获矩和端损失 | 稳定积分与对数域运算代替中间溢出和指数裁剪；按相对电势及相对能量计算分布与俘获条件；验证实际返回电势的残差 | 补充损失锥的 refill 参数是经验闭包；极小数可下溢，无法表示的必要结果须失败 |
| 双流体压力组合 | 明示独立总压拟合与物种压力和的差；可显式要求物种求和一致 | 独立拟合能力保留，残余应力不是新增且已验证的物种 |
| 损失锥本征谱 | 正则偶解与连续相位排序保留整数阶模态；另检端点 | 这是规定角向边值问题的数值解，不证明任意截断模态和都代表真实等离子体 |
| Frank–Egedal 速度矩 | 密度与两种压力使用同一个速度区间；处理可达轨道与可积端点奇性 | 对模态和采用非负部分仍是所声明的模型选择；积分加密一致不是任意回调的全域证明 |
| 平行平衡与 mirror/firehose 诊断 | 使用固定磁通面的偏导，并修正 mirror 判据符号 | 必须提供真实固定磁通偏导或相应采样轴；这些局部判据不是完整稳定性分析 |

零力附近同时给出未经改写的绝对、相对残差与浮点传播估计。消除数值噪声不能替代物理残差检查，也没有放宽既有科学测试的容差。

Frank–Egedal 的共同分布矩定义与所刊垂直压力积分下限存在需要明确解释的差异。本版本按共同分布计算三个矩；旧 `perp_velocity_lower` 参数作为共同下限的兼容别名，不能再只裁掉一个压力分量。此处没有宣称作者已确认勘误。[原论文](https://arxiv.org/html/2509.17288)

## 阅读与决定范围

当前 32 份各向异性算子、闭包和图的唯一开发文档位于 `catalog/examples`，按本版选择清单列出的 callable 收录；先前 Pleiades 的 53 份限定文档位于 `catalog/pleiades-maintained`。所选分发的 catalog 为这 85 份文档提供路由与逐项记录。未改变的先前关系沿用原科学资格；本次版本绑定变化不产生新的科学证明。

原始实现、原失败和旧行为断言分别保存。修正后的测试不把旧失败改写成原版本通过。先前 Pleiades 的四项固定网格单调性失败仍保留；五个旧 Green/filament 家族仍按有依据的不同变体保留，本次不删除它们。

本版供内部科学审阅。最终保留的新增或改变项仍需逐项或明确清单的人为决定。历史本地扩展的再分发权没有由源码存在自动建立；本版保留原 Pleiades MIT 声明及来源说明，不代表对整个扩展的公开发行许可。没有实验普适性、完整项目 D2/D3、人工科学批准或公开发行结论。
