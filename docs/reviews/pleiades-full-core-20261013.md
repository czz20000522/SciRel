# 轴对称核心物理能力后继：科学审查材料

## 本次科学变化

圆环 Green 组合增加 ψ、BR、BZ 的目标行/源列矩阵，默认每源单位电流响应，保留实际坐标、原有序号、有符号权重及独立驱动电流。共享核修正近导线分子消差，并采用数学等价的超几何分区评价；没有用距离截断抹掉细小源或轴上 BZ。独立高精角积分检验值、符号、形状、排列、轴限和近丝响应。源集合直接核、离散零自点矩阵、镜像域矩阵及径向梯形积分磁通的奇异点与规范合同分别保留。

压力反馈对下降存储坐标只排序物理中平面拟合索引。终态电流、Green 轴和返回数组保持调用者顺序。独立上升/下降坐标组合确认相同的科学关系，非收敛状态也诚实保留。

自由边界反馈修正三种真实缺陷：接近单位松弛时不能仅凭很小的松弛后更新提前结束；磁通不变时不能忽略仍变化的场和电流；迭代进入零场非法域时必须先拒绝，再调用压力闭合。回归保留原失败，停止判断绑定未松弛固定点和完整终态，而非调整容差。

压力 EQDSK 后继将终态磁通、总电流、P 与 dP/dψ 写入明确的 Pleiades 方言，拟合域外为零。输入必须已收敛且网格形状一致，调用者负责同一物理网格；结果对象没有坐标身份，不能宣称自动验证任意同形网格的物理同一性。该格式不存二维 Jφ/P，也没有 F、q 或 EFIT/COCOS/GENRAY 资格。

## 已有失败的独立判定

27 条前行失败同时出现在旧、新运行基线，不能归因于升级。其科学期望逐项依据方程、单位、边界和域判定：节点域梯形权重与显式单元边界是不同面积合同；定 ψ 压力导数必须给定或可独立推断；镜像裕度使用 `B²/μ0 + B ∂P⊥/∂B`；Boltzmann 指数不能用截断代替不可表示失败；热离子密度和平行/垂直压力须消费同一速度总体和截断。其余非法密度、非有限残差、重复坐标与反馈状态使用显式失败或终态关系。

确认过时的测试期望以独立推导及既有限定合同修正，保留原数值强度和容差；确认实现缺陷则先写反例，再修实现和正式合同。没有删除失败、xfail 或把观测输出反填成期望。已接受后继中的四条固定场插值器加密场线单调性失败单独保留：加密采样线不保证固定场插值误差单调下降。
