# SciRel 0.1.0.dev9

这是 Git 管理的开发候选说明，不是公开发行批准。

- `pyproject.toml` 是版本的唯一来源；源码 checkout 与已安装 wheel 都从同一元数据读取 `scirel.__version__`。
- NumPy、SciPy 和 mpmath 保持在核心运行闭包；Matplotlib 与 netCDF4 移入可选能力和测试闭包。
- 当前 wheel 仍是纯 Python 的 `py3-none-any`。它不把 Octave 等系统运行时伪装成 pip 依赖，也不把未验收的平台写成通过。
- Linux x86_64 + CPython 3.14 clean-venv 回执已完成：核心依赖安装、`pip check`、简单算子和跨域 TaskGraph 均通过。确切回执由 `release/CURRENT.json` 绑定。

当前候选的源提交、wheel 摘要和平台状态以仓库根目录的 [`release/CURRENT.json`](../../release/CURRENT.json) 为准；候选完成前不创建新的 `release/wheel/versions/` 或 `release/docs/versions/` 复制记录。
