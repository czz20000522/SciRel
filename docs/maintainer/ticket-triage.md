## 撤出的 11 张怎么处理

**不是删掉。** 工单不删除，状态改成 `closed`，`resolution` 写清"按什么依据、谁定的"。
之后按依据改代码/合同/文档，改动本身进 PR，和普通工作一样受门禁约束。

依据分四类，都可以复核：

1. **规范/上游有明确约定**（`0002`、`0005`）——实测上游行为，照它的约定统一；
2. **合同是代码的衍生物**（`1202`）——按代码改合同；
3. **缺陷**（`0905`）——修工具，让它失败而不是静默；
4. **措辞与记录**（`0600`、`0100`、`1200`、`1201`、`0004`、`1203`）——直接改，不需要裁决。

## 一处需要特别说的：`0005` 的取值

维护者批准破冻。统一成**弧度**，实测依据：

```
scipy 1.18.1  from_euler(seq, angles, degrees: bool = False)
              as_euler(seq, degrees: bool = False)
numpy         np.deg2rad / np.rad2deg —— 弧度是默认单位
```

所以：**属性与返回值一律弧度（无量纲 `float`）；需要度的地方用显式开关 `degrees=True`，或参数名带 `_deg`。**
让"忘了转换"变成必须显式写出来的事，而不是靠记性。
