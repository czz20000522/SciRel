# Maxwellian FFT 缩放可表示性修正

独立审查 GPDF-R3 在 `z=-26.625j` 发现：复误差函数 w 仍为有限值，但乘以 `i*sqrt(pi)` 后的 Z 已不可表示。前驱只检查 w，返回了 inf；本后继在最终缩放后独立检查全部结果，失败抛 FloatingPointError，不返回矩阵部分结果或非有限响应。

先保留真实失败回归，再修正实现。回归包括标量和混合矩阵、16/32 阶的正常邻域，以及由 `sqrt(log(float64_max)-log(2*sqrt(pi)))` 推得的负虚轴缩放边界两侧。对照值来自数学恒等式与 SciPy 特函数，未读取来源捕获答案。

首次新增测试把 -26.62 和随后 -26.618 误列为有限 Z 邻域；实际边界约为 26.6179864。两次失败日志保留。最终有限邻域改取 -26.61/-26.60，并增加明确数学边界两侧测试。此举改正新测试的输入分类，不放宽数值断言、容差或已有科学输入域。

原前驱源码、wheel、独立反例与成功的有界 D3 证据保持不可改写；后继资格以新确切 wheel 的独立断网完整运行和主控接收为准。
