## R1：Gaussian 导数

定义 `Zp=∫exp(-v²)/(sqrt(pi)(v-z)²)dv=-2(1+zZ)`。
后一恒等式在大相位处直接浮点计算会相消，不能通过放宽绝对容差接受零响应。
修正以 k=1/sqrt(2)、omega=z 调用原始极化率，因此 `chi=2(1+zZ)`、`Zp=-chi`。
读取的是原始 chi，不是从已舍入 epsilon 减去 1，避免重演同一损失。

复用的 Gaussian 矩展开给出 `Zp=z^-2[1+3/(2z²)+15/(4z⁴)+…]`，
和平方核展开的偶 Gaussian 矩一致。下半平面须保留
`-4i sqrt(pi) z exp(-z²)`，实轴保留其半贡献；代码采用对应 4/2 因子。
在纯虚轴上，偶实密度保证导数为纯实数，消除浮点残余虚部有数学依据。

| 范围 | 审查结果 |
|---|---|
| |z|<12 | 保留直接恒等式，测试以高精度方程验证 |
| |z|=12 切换及相邻点 | 高精度 oracle 包含实轴、虚轴和上下半平面的多个角度 |
| 12≤|z|≤1e150 | 原始极化率和 Gaussian 矩展开，不进行单位项相减 |
| 更大有限相位 | 宽精度倒数保留可表示主项及延拓；更高代数项已低于 float64 范围 |
| 导数超出表示范围 | 即使 Z 本身有限，也必须拒绝整次调用；测试包含 -26.6i |

已有 oracle 以 80 位平方核积分独立核对 `1e8+i`，并以 erfc(12)<2e-64
说明省略尾质量。严格尾部误差需要结合核界，不应将该单点证据推广成全复平面认证。
宽精度计算依赖当前 NumPy 平台的 longdouble 表示能力；本轮安装验收绑定实际 Linux
环境，不证明其他平台具有相同宽度。

## R2：top-hat

单位密度支撑 [-.5,.5] 的变换为 `∫dv/(v-z)`。
远场级数 `Z=-z^-1 Σ[(1/(2z))^(2n)/(2n+1)]` 是收敛展开；在 |z|≥1
比值模至多 1/4，128 项上限充足，停止判据随舍入水平判断。
导数精确为 `1/((z-.5)(z+.5))`，顺序宽精度除法避免相邻倒数相减及中间乘积溢出。
近支撑的对数分支必须满足：上半平面虚部为正、下半平面为负、实轴内部取上侧 +iπ，
实轴外部虚部为零；端点保持显式拒绝。

独立来源 `TOP_HAT_RECONFIRMATION.json` 已更正原 complex np.log1p oracle：
原 oracle 在 `1e16+i` 约有 11% 误差；180 位直接积分与收敛级数一致，
仍确认被审前驱返回零是实现缺陷。不能用那份错误 oracle 宣称失败已消失。
当前新测试使用直接积分、收敛级数及高精度公式，并按实虚分量分别使用零绝对容差。

第一轮主控结果 93 通过、2 失败中，纯虚输入的导数 oracle 留有约 1.7e-150 的
伪虚部；实际导数严格为实数，不能要求实现复现任意精度舍入噪声。
应把 oracle 改为精确有理结构 `1/(z²-.25)` 或显式数学对称性，保留零绝对容差。
失败记录必须保留，不将这一 oracle 修正算作容差放宽。

前一近轴修正仍会在顺序计算 z±.5 时抹去极小实部，使导数的微小虚部分量消失。
新增 4 项严格回归先记录失败；最终导数显式组成二次分母：
`Re denominator=(x-.5)(x+.5)-y²`、`Im denominator=2xy`，再取一次宽精度倒数。
实部的因式形式保留端点距离，虚部的交叉项在加减 .5 前保留；符合
`Zp=1/(z²-.25)`，不再要求实现通过非零绝对容差掩盖微小分量。

显式 Hilbert 表达式路径也需保持大相位导数。修正采用
`Cauchy[v*f']/z=Cauchy[f']+integral(f')/z`；合同要求端点消失，故 integral(f')=0。
这不是从已舍入 Z 或 epsilon 重建导数。下半平面解析延拓中
`(z*f'(z))/z=f'(z)`；实轴上侧主值边界的加项同样正确。
阈值 |z|≥12 仅切换数值表达式，保留原表达式、网格和所有半平面定义。
私有 epsabs 参数按 1e-10/|z| 传入离轴 Cauchy、实轴外部和 PV 求积路径，
epsrel 未放宽，四个既有资格化 API 未改变。

先记录的 6 项中心/平移 Gaussian 显式 Hilbert 失败回归与最终加权修正对应。
