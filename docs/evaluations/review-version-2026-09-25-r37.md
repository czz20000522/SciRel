# SciRel 待审快照身份报告 successor r37

状态：开发期冻结待审，不是领域专家认可、可信版本或公开发行。没有上一可信基线，首次科学审核仍涉及全部 68 项；r36 只是未认可的开发比较版。

## 工程变更与边界

`scripts/review_scope.py` 的首次审核和快照对比报告现在分别给出 `candidate_manifest_digest` 与 `comparison_manifest_digest`，值是参与本次计算的原始 manifest 字节 SHA-256。仅改 manifest 排版会改变快照身份，但不会因此扩大科学差异或反向依赖集合。安全复核发现最初实现的解析与摘要使用两次读取，可能在并发改写时错绑；已改为从同一字节缓冲解析和计算摘要，复查不再有该问题。

此摘要可作为未来异步版本级审核的精确目标，但**不是**审核者身份、专家授权或科学认可证明。现有 `ReviewDecision.reviewer` 仅为字符串，逐项 `approved` 也不能批准完整版本。真实可信晋级仍需可验证的人工身份/授权事件或等效签名，并把决定绑定到确切待审快照和审核范围；在此之前旧发行入口保持关闭。对 CodeFusion 的潜在需求仅是中性的、可校验的人员审核事件，不要求其理解 SciRel 的科学状态。

没有改变 `src/scirel`、公共 callable、科学 exact documents、开发 catalog 或 wheel。相对 r36 无新增科学合同或实现增量，原 r35 磁通合同仍待审。合格 L1 交付目录为空，来源资格、许可证和专家认可均未因本轮工程更改而获得。
