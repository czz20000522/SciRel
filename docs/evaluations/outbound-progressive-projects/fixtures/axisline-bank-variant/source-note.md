# Synthetic winding-bank handoff

The two banks are idealized axisymmetric circular current sources in vacuum. Each bank's signed `net_ampere_turns` is for that whole bank, not for each numerical node. Its current is shared equally among its `radial_nodes` by `vertical_nodes` representative filaments. Radial and vertical pitches are center-to-center spacings in metres. The axisline is at cylindrical R = 0; the listed heights are in metres. There is no measured device, plasma current, material boundary, or uncertainty model in these files.
