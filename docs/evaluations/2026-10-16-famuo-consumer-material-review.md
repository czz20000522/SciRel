# 伐谋平台消费材料出库复核（内部）

日期：2026-10-16

## 复核范围

本记录保存消费材料形成过程中的内部复核结论。它属于 SciRel 开发与发布审查记录，不随外部消费包分发。

## 发现的问题

- 外部案例能够执行算子和任务图，但缺少从用户目标、合同选择、组合边、执行检查到交付的可复核过程。
- 跨领域案例需要把单位和字段边界写成显式连接，不能从字段名或数量推断。
- 现有源码续作必须分别保留源项目基线与差异、源测试结果、SciRel wheel 运行结果；其中任何一项都不能替代另一项。
- 内部会话对照和出库修补理由不属于消费者需要的材料。

## 采取的修正

- 将案例过程改写为面向消费者的标准参考流程，要求需求规范化、最小合同检索、显式组合、分层检查和有界交付。
- 在跨域案例中明确温度单位、字段归属和适配边。
- 在源码续作案例中明确基线、补丁、回归测试和独立 wheel 验证的交付结构。
- 从消费包移除本记录及所有会话对照内容；消费包只保留 wheel、文档、消费 skill、案例、运行依赖和必要收据。

## 验收边界

消费包的安装、查询和三个案例运行已在 Home Linux amd64 Docker 环境完成。宿主平台联调、科学 release approval 和源码续作的完整 Agent 补丁验收仍按材料中的状态字段记录，不由本记录提升。
