## R1：Gaussian 导数的冷极限消失

定义密度 f(v)=exp(-v²)/sqrt(π)，Zp=∫f(v)/(v-z)²dv。前驱直接计算 -2(1+zZ)，在 z=1e8+i 时大数消减使约 1e-16 的实部变成零；独立平方核积分和 Gaussian 矩同时确认缺陷。

保留小相位直接恒等式；|z|≥12 时复用已经资格化的 Maxwellian 原始 susceptibility 推导。令 k=1/sqrt(2)、ω=z，χ=(1+zZ)/k²=2(1+zZ)，所以 Zp=-χ。直接使用内部函数返回的 χ，不从已舍入 ε 中减去 1，也不构造可能溢出的 sqrt(2)z。已有 `maxwellian_electrostatic.py` 的字节保持不变，摘要为 `6d3bb9a6e915c56f70a4776fc7386a1631ab5f82d0590e8bed233eecc34df985`，实测与前驱一致。

|z|>1e150 时下一代数项量级已经低于 float64 可表示范围，使用宽类型的首项 1/z² 和原有精确指数延拓，避免 Python 复数绝对值溢出。下半平面指数贡献为 -4i sqrt(π) z exp(-z²)，实轴保留半贡献。纯虚轴 Zp 的虚部按偶实密度对称性精确置零。派生 Zp 不可表示时显式拒绝整个调用；Z 有限并不保证 Zp 有限。没有缩小接受域或改变默认分布。

## R2：top-hat 远场及小分量消减

单位密度区间 [-.5,.5] 的 Z=∫dv/(v-z)，Zp=1/(z²-.25)。前驱两个复对数相减在 z=1e16+i 返回 Z=0；原始独立 complex-log1p oracle 本身也有误，后续直接积分与收敛逆幂级数一致确认原缺陷。错误 oracle 与原始日志均保留，不把它作为最终依据。

远场 |z|≥1 使用收敛级数：

Z=-z⁻¹∑[(1/(2z))²]ⁿ/(2n+1)。

公比模不超过 1/4；停止条件为项小于 float64 ε×累计和模/4，最多 128 项。宽倒数保留远场极小分量并避免不必要的平方溢出。这是从有限积分的几何级数得到的收敛表达式，不是任意阶渐近猜测。

独立复核又发现近中心 x≈0 的实部和支撑外极小 y 的虚部仍可能被近场两个对数相减吞掉。近场令 z=x+iy：

- |x|≤.25 时实部使用 .5 log1p[-2x/((x+.5)²+y²)]。这是实数 log1p；其参数远离 -1，不使用已知有误的微小复数 log1p。
- 其他近场实部使用 log(hypot(x-.5,y))-log(hypot(x+.5,y))，保留端点距离。
- 虚部直接为 atan2[y,(x-.5)(x+.5)+y²]，避免两个近邻角相减。实轴显式选取上边界：支撑内部 +π，外部 0，包括输入 -0 虚部。

所有现有分支、矩阵形状与端点显式失败保持。导数分母分别计算实部 (x-.5)(x+.5)-y² 和虚部 2xy，再作一次宽类型复倒数。这样既保留端点距离，又在任何 ±.5 平移之前保留极小 x 的交叉项；例如 x=1e-100、y=.1 的非零导数虚部不会被平移吞掉。

## 同族 R1：显式 Hilbert 输入的冷极限

只修默认 selector=0 不足以覆盖同一核心输入：显式 Gaussian 及平移 Gaussian 表达式仍会在 Cauchy[f′] 中相减丢失冷极限。主控的具体反例为 z=1e8+i、f(v)=exp(-(v-2)²)/sqrt(π)，并保存 6 项独立高精度回归的真实 RED 后才修改代码。

对于已声明边界衰减的解析密度，∫f′dv=0，故

Cauchy[v f′]=∫[1+z/(v-z)]f′dv=z Zp。

|z|≥12 的显式 Hilbert 导数改为 Cauchy[v f′]/z；其被积分密度的总量为 -∫f，从而避免旧导数密度的零总量消减。复用已资格化 Cauchy 的已知尖核与特征网格处理；不另写平方核无限积分。内部绝对容差为 1e-10/|z|，原相对容差保留；不把 callback 乘以巨大 |z|，以免引入新溢出。解析延拓同样用 z f′(z) 后除以 z；实轴 PV 使用同样的局部求积与失败闭合。小相位行为保持。该恒等式不替调用者证明密度特征网格、尾部或边界衰减，具体 Gaussian 通过也不代表任意解析表达式的全局相对精度证明。
