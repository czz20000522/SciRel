## 科学增量与接线影响

[平衡合成点诊断图](../../catalog/examples/scirel.diagnostics.equilibrium-synthesis-diagnostics.json)的历史 `flux_loops` 键在现有实现中只对调用方 `equilibrium.psi` 做双线性点采样，输出保持输入 `psi` 的单位。旧 exact document 与维护图 YAML 将该输出固定标为 `Wb`，但当前 SciRel 自由边界平衡的 `psi=R A_phi` 是 `Wb/rad`；两个图直接接线不会自动得到完整圆环磁通。现在明确该键的数值与单位边界，并在[直接反演图](../../catalog/examples/scirel.inference.direct-anisotropic-inversion.json)的限制中说明：以物理 `Wb` 磁通环观测拟合时，需要调用方提供有依据的兼容诊断关系。对于轴对称圆环这一制造条件，r21 的注入端口显式使用 `2*pi*psi`；不能无条件把此变换推广到所有诊断几何。

新增回归以 `B_Z=1 T` 的解析 `psi=R²/2` 制造输入，在网格点断言历史 `flux_loops` 输出仍为 `psi=0.08 Wb/rad`，而不是 `2*pi*psi Wb`。它保护现有图的实际无换算行为，同时暴露其名称可能造成的误读；不新增仪器模型，也不更改旧数值结果。维护的图 YAML 和两份领域草稿同步说明该边界。冻结的 L1、旧准入来源记录均未改写。

证据只覆盖一个解析坐标样本、原有插值/分支/失败测试和文档合同；它不证明真实磁通环标定、仪器响应、任意三维几何、平衡场物理有效性或反演科学正确性。领域专家仍需决定物理观测所需的诊断关系及适用域。来源许可证、首次可信版本资格和公开发行均未完成；确切执行与内容摘要见本版 `test-evidence.md`。
