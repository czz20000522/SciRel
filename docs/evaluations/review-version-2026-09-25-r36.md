# SciRel 资产文档受影响测试 successor r36

状态：开发期冻结待审，非领域专家认可、可信版本或公开发行。上一可信版本仍不存在，首次科学审核集合为全部 68 项；r35 只是尚未认可的开发比较版。

## 工程变更

`scripts/select_affected_tests.py` 原将 `catalog/examples/*.json` 变化一律映射到文档测试，未选该资产的直接科学测试与反向依赖 TaskGraph 测试。现在按当前 exact document 文件定位资产，并沿文档声明的依赖 ID 选择精确闭包；找不到当前资产映射时 fail closed 到全套。公共 Schema 变化仍执行文档门禁，普通说明文档不触发科学测试。回归先复现旧漏测与未映射路径的错误，修复后通过。

这只改变开发测试的选择，不改变科学 callable、exact document、catalog、wheel、已有验证容差或旧审核记录。相对 r35 没有新增科学合同或实现变化；r35 的圆丝网格磁通更正仍待专家审核。`0.1.0.dev18` 开发 wheel 和 68/68 catalog 可复用其确切字节；本轮不据此声称 D1 来源资格、科学认可或发布。

## 审核边界

此选择器依据路径而非 JSON 字段级差异。单纯翻译或排版变更也会运行该资产的直接和反向图测试，但不会扩大到全仓；这是在未知变更语义下避免漏测的有界成本。它不判定科学等价，也不代替 `scripts/review_scope.py` 对两份冻结版本的科学增量比较。首次专家审核仍不能按一次工程改动缩小为零。

合格 L1 交付目录继续为空。版本级专家认可、来源许可证和公开发行门禁仍未完成。
