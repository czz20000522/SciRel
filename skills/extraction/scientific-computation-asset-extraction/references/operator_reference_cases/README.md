# Reference Cases

这些案例用于训练和审查 `scientific-computation-asset-extraction` 的 operator 输出形态。它们不是一次正式抽取运行的交付目录。当前案例同时覆盖 Python 和 C reference profile，不表示算子只能使用这两种语言，也不覆盖 task graph 包形态。
案例只演示产物形状、证据写法和验证习惯，不定义默认科学领域。

## 案例说明

- `速度空间反应率积分`: 演示源码函数可以直接 import/run 时，测试应做 direct source parity。
- `线圆柱交点诊断几何`: 演示源码无法构建时，测试可使用源码派生 fixture、物理/几何不变量和边界行为。
- `RZ极角矢量变换`: 演示支撑核如何收窄为独立物理核，并避免把源码中不互逆的两个函数包装成误导性双向算子。
- `C语言格林矩阵电流投影`: 演示只有 C profile 能满足交付约束时，如何保留矩阵投影核心并显式补齐数组布局、状态码和边界检查。

## 注意

案例内的 Python 或 C 实现都可以独立运行，用于证明对应 reference profile 的参考案例质量；它们仍然是模板资产，不是当前阶段要求产出的正式算子包，也不是未来唯一允许的实现语言。
