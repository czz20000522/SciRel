# D2 decomposition packet

Bind one packet to the frozen D1 manifest, candidate/dependency digests and
complete received denominator. For each retained relation record:

- claim id, target/ports, variables, units, axes, assumptions and applicability;
- source-fidelity observation versus independent scientific claim;
- proposed discriminating oracle/check, original grid/threshold/tolerance and
  failure cases;
- observation (`passed`, `failed`, `blocked`, `NOT_RUN`, `inapplicable`), exact
  command/evidence refs and hashes; and
- correction hypothesis, affected reverse dependencies, claim ceiling and next
  development owner.

Keep a missing oracle or runtime as a gap. Do not convert a plausible equation,
source match, test count or worker report into a correctness result.
