# D3 decomposition packet

Bind one packet to the exact D2 candidate/catalog, runtime profile and
normalized application case. Preserve the complete declared case matrix,
including normal, boundary, bad-input, recovery, convergence and repeatability
cases when applicable.

For each case record input and output hashes, selected capability identity,
command, runtime/dependency identity, observed values, failure/exit status and
state. Read the result through the consumer path and keep computed observations
separate from physical interpretation, library correctness, approval, rights
and release. Return uncovered, blocked and `NOT_RUN` rows, claim ceiling and
the next development owner; a successful case is never library-wide proof.
