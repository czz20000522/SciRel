# Evidence Record

Use one compact row or test header per scientific claim:

| Field | Content |
| --- | --- |
| Asset / relation | Stable callable or declared equation |
| Question | source fidelity, science, numerical method, composition, or functional reassembly |
| Gate | catalog gate name |
| Oracle | independent formula, residual, fixture, invariant, or reference |
| Input regime | grid, units, boundary, seed, configuration, and fixture identity |
| State lifecycle | initialization source, frozen/recomputed policy, update order, persistence, and branch |
| Output coverage | compared fields versus the complete declared terminal scientific schema |
| Acceptance | tolerance, exact property, or expected order |
| Observation | actual metric and command/runtime reference |
| Result | pass, fail, inapplicable, or blocked |

Summarize the strongest earned status only after all rows are evaluated. Keep machine-readable
execution output in validation evidence, not in `operators/` or `task_graphs/`.

For corrections, add the observed defect or feedback binding, predecessor and successor versions,
before/after relation, expected source divergence, unaffected-domain comparison, independent corrected
oracle and complete affected graph outputs. Distinguish actual execution from a proposed check.
The affected scientific page contains the error/rationale/change explanation; raw logs and evolving
pass counts remain here. Consultation messages, author self-checks and human approval are not aliases
for a platform validation record. Keep the four claims separately readable: source fidelity,
independent relation/numerical validation, composition/terminal state, and applicability limits.

Recorded modification snapshots and their bounded validation logs are improvement history, including
unsuccessful versions. Keep content and run events separate: a re-run need not create new content, and a
new snapshot cannot inherit an old passing binding. Retention is an owner policy; this skill returns the
exact evidence artifacts and does not turn scratch output into durable truth by itself.
