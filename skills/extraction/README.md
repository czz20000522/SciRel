# SciRel decomposition skill bundle

This directory is the standalone D0-D3 decomposition package. Give the bundle,
the target project and an authorized Codex/Claude execution environment to a
worker; the result is a digest-bound decomposition packet for a separate
development owner.

The five original D0/D1 skills preserve source intake, extraction, validation,
operator review, relation implementation and runtime observation. The two
stage entrypoints add D2 claim decomposition and D3 application observation.
They emit raw material and evidence only. They do not import a development
checkout, merge candidates, modify a user project, approve, publish or release.

Build with `scripts/build_extraction_skill_bundle.py`. The manifest fixes the
seven entrypoints and their bytes; a bundle digest proves the payload, not
scientific truth or downstream acceptance.
