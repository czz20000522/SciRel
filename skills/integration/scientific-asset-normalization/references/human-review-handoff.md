# Final human review handoff

Humans approve the stable final scientific increment, not each intermediate choice.
D2 can compare, repair, integrate and build a development wheel; D3 can test it.
Independent Agent review records real identity/model and findings without claiming human endorsement.

Use [scirel-review-preparation](../../scirel-review-preparation/SKILL.md).
Compare with the previous trusted baseline, including cumulative changes.
Only retained new/changed assets need documents and review units. Reused/duplicate inputs retain target version,
lineage and evidence. No-change batches do not enter review.

Freeze documents, actual code/tests and evidence after appropriate validation.
Submission checks bindings and coverage, not scientific truth.
Upload fixes initial versions. Reading is not approval; leased edits create successors and putting an item back
does not complete review. Explicit decisions bind exact versions. AI rework is separately submitted as a linked
successor; the original producer need not remain running.

Approval covers the reviewed version. Packaging corrections may reuse science but new bindings still need checks.
Material science/API/dependency changes need successor review.
Approved subsets cannot promote wheels containing unapproved increments.
Public release also requires authority, licenses and existing release checks.
