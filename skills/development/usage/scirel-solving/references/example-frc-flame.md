# 示例：FRC 平衡与性能分析

这是虚构教学场景，未执行、无实验数据或数值结果。能力选择必须重新查阅实际公开合同。

用户说：“有磁探针、密度/温度剖面和线圈电流，想分析这一炮的平衡与约束，看看能否支持下一轮实验。”

## 先澄清物理问题

“分析平衡”可能指测量驱动的平衡重构，也可能只需 0D 性能估计；它们的输入与结论不同。先复用文件头和已有回答，再分轮询问会改变结果的缺项：

- 所需模型与输出：重构磁轴/分界面，还是只给量级？
- 数据单位、时标、坐标和线圈电流正方向是否已有约定？
- 边界与压力闭合是否已知？“支持下一轮”的参考或判据是什么？

缺失单位或模型时不从相邻 API 默认值猜测。可给条件分支，或只交付输入已充分的子结果。

## 按关系检索和编程

```text
线圈几何/电流 → 真空场
测量与剖面 + 明确边界/闭合 → 平衡重构 → 磁轴、分界面
已解平衡 + 剖面 → 性能量 → 与用户给定参考比较
```

分别查询这些关系并读完整合同。真空场不包含等离子体响应；给定分界面通量的材料分区不等于从测量定位分界面；规则网格采样不自动允许外推。名称或单位相同不足以保证连接成立。

可能需要的补充步骤包括几何离散、时标对齐、分界面定位和性能公式。逐项说明方法并选择检查：总电流守恒与离散加密、已知剖面对齐、对称性/独立定位对照、量纲与已知极限。未验证的分界面定位不能支撑绝对位置结论；自写性能公式也不继承 SciRel 验证。

## 给出实际证据边界

真实执行后，数值从保存的输出生成。先给磁轴/分界面或性能量、单位、与用户判据的比较和主要限制；再给改变结论的假设、补充科学及未运行项。无法支持的量标为"未运行"。

本示例没有运行，所以只能说明这条工作路径，不能填入目标数值、通过状态或装置级结论。
