## 要决定的问题

`scirel/kinetic/generalized_dispersion.py` 实轴主值分支里的近奇异替换：

```python
def regularized(velocity):
    offset = velocity - real_point
    if abs(offset) < 1e-7:
        return float(derivative(real_point))
    return (density(velocity) - density_at_point * np.exp(-offset * offset)) / offset
```

该分支**是可达且正确**的：它在 `v -> z` 处取可去奇点极限 `f'(z)`。本单要决定的是：是否需要额外
把它在代码里标注为"防御/极限路径"，还是现有测试覆盖已经足够。

**本单已撤回两件事**（前一版写错了，留痕）：
1. 撤回"任何公开输入下不可达"——采样式论证只能说明"这些输入没走到"，不能证明不可达；
2. 撤回"选项 A 删除"——被删的会是一段正确实现。
