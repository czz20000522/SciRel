## 要决定的问题

**初版论证错误，已被反例推翻，本单改为说明性记录。** 初版声称"非负剖面的最大范数相对变化以 1 为界，故
`truncate >= 0.1` 时种子关系的重入分支不可达"。该论证只界住了一侧（`c_i - p_i`）；`p_i - c_i` 不被
`max(c)` 界住，因此当 `previous` 远大于 `current` 时比值可以任意大。反例（公开 API）：

```
evaluate_neutral_outer_seed_convergence([4.0, 0.0], [1.0, 0.0], truncate=0.2)
→ seed_error 3.0, reentry_threshold 2.0, should_reiterate True
evaluate_neutral_outer_seed_convergence([10.0, 0.0], [1.0, 0.0], truncate=0.2)
→ seed_error 9.0, reentry_threshold 2.0, should_reiterate True
```

所以"死分支"并不存在，初版给的 A（收窄 `truncate`）/B（记录惰性）/C（改判据）都在讨论不存在的问题。
现在的判据是 `max|previous - current| > 10*truncate*max(current)`，其触发条件取决于 previous/current 比值，
与 `truncate` 无单调关系。要请审核人确认的只有一件事：**这个判据形状是否符合调用者意图**。

## 选项

**A（推荐，零改动）**：接受现状，本单作为说明性记录留存，审核人确认后关闭。依据：合同已写明触发条件与
反例，回归测试
`tests/neutrals/test_convergence_and_mesh_evidence.py::test_seed_threshold_is_exactly_ten_times_the_outer_threshold`
断言反例 `should_reiterate is True`。影响：无行为变更。

**B**：若认为判据形状需要改（例如把"分布剧烈变化"与"阈值大小"分开表达），另开一张新工单，附新判据与前后
对比，按 B 级评审处理；本单不提议任何改法。影响：新工单需要独立证据，冻结期内不合并。

## 各方意见

无分歧：初版结论已被反例推翻，双方一致认为不存在死分支。剩下的只是"记录留存还是另开改进单"这一流程选择，
因此 reviewers_required 仍为 2，但预期没有实质争论。

## 不决定的后果（已执行的安全默认）

实现与声明范围都不动。两份合同（`outer-seed-convergence`、`outer-convergence`）的 `known_limitations`
已撤掉"不可达/无条件收敛"的说法，改为"重入条件为 `max|previous − current| > 10·truncate·max(current)`；
仅当 `max(previous) ≤ 2·max(current)` 时比值 ≤ 1，previous 远大于 current 时任意大；示例
`([4,0],[1,0],truncate=0.2)` 给出 3.0 > 2.0 并重迭代"；中英同步。反例已钉成测试。
