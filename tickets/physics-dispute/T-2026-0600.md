## 要决定的问题

`vp_distribution(vv, Fn=2, kappa=1)` 对 Lorentzian 平衡态返回
`(wr, wi) = (1.0, -k*sqrt(2))`，docstring 把它称为 "the exact root"。**这一措辞应当撤回**：
按本条实现自己的线性化约定（`d(df)/dt = -i k v df + E f0'` 配 `i k E = -dv sum(df)`，
时谐因子 `exp(-i omega t)`），该色散条件的根不是这一对值；而且**当前返回的阻尼根是该约定
加有限速度窗截断的产物，不是被证实的物理色散根**。要决定的是：（A）按现有约定改正符号、
（B）如实记录约定与截断并保留现状（不称其为 exact）、（C）干脆不返回理论值，由调用方自算。

### 仓库内的事实（可直接复现）

1. **归一化常数与闭式积分。** `Fn=2, kappa=1` 的密度是
   `F(v) = c/(1+v^2/2)`，`c = 1/(pi*sqrt(2))`，即 `F = (a/pi)/(v^2+a^2)`、`a = sqrt(2)`。
   `tests/kinetic/test_vlasov_poisson_evidence.py::test_lorentzian_dispersion_integral_matches_its_meromorphic_closed_form`
   在 40 位下把 `integral F'(v)/(v-z) dv` 与亚纯闭式 `1/(z - i a)^2` 对到约 `1e-41`
   相对（三个复数点），并断言 `pi*a*c = 1`。

2. **本实现自身约定给出的根。** 令 `df = g(v) exp(-i omega t)`、`zeta = omega/k`，稳态条件为
   `1 = (1/k^2) integral F'/(v-zeta) dv`。代入第 1 条的闭式：
   `(zeta - i a)^2 = 1/k^2`，即 `zeta = i a +- 1/k`，也就是
   `omega = +-1 + i*sqrt(2)*k`。上报的 `wi = -sqrt(2)*k` 与之**符号相反**。

3. **半离散谱与解析根不可比（这一条只是推理与已知局限，不是已证结论）。** 直接构造
   `A = -i k diag(v) + (i/k) dv outer(f0', 1)` 并取特征值，`nv` 从 256 到 4096、`vmax`
   从 20 到 40 时 `omega = i*lambda` 的虚部最大绝对值约 `4e-15`，即谱是纯实的。
   **但这不能推出"真实根是实的"**：Lorentzian 的尾部按 `1/v^2` 衰减，Landau 阻尼正来自
   尾部共振粒子，把 `vmax` 截到 20–40 相当于切掉了产生阻尼的那部分分布，所以这个纯实谱
   更可能是**截断的后果**——这是**推理，不是证明**：本批没有做过放大 `vmax` 直到尾部可忽略的
   收敛实验，也没有做解析延拓，所以"纯实谱"只能作为**已知局限**记录在合同的
   `known_limitations` 里，**不得**写成"该模型的谱是纯实的"这样的已证结论。要让这条可比，
   需要把 `vmax` 扩到尾部可忽略（Lorentzian 收敛很慢，不是几百个节点的事），或改用能代表
   尾部的解析延拓；两者本批都没有做。

4. **数值吻合不能当作正确性的证据。** `solve_vlasov_poisson(2, 1.0, 2048, 0.01, 2000, k=0.15)`
   的 `vp_diagnostic` 给出 `gamma = -0.207`，与上报的 `-0.2121` 相差约 2%；但 `vp_diagnostic`
   是在有限时间窗内对峰值取最小二乘斜率，相位混合与网格复现时间都会介入，这是**短时拟合**，
   不是衰减率。因此这条 2% 的吻合既不能证明上报值正确，也不能证明它错误。

```python
import numpy as np
from scirel.kinetic.vlasov_poisson import vp_init
s = vp_init(2, 1.0, 512, 0.01, 1, k=0.15, vmax=20.0)
A = -1j*s["k"]*np.diag(s["vv"]) + (1j*s["dv"]/s["k"])*np.outer(s["df0dv"], np.ones(s["vv"].size))
print(np.abs((1j*np.linalg.eigvals(A)).imag).max())   # ~3e-15: real spectrum
```

## 选项

**A. 改正符号**：`wi = +k*sqrt(2)`，并在 docstring 写明"该根位于上半平面，故在此约定下
Lorentzian 无 Landau 衰减"。依据：第 1、2 条的精确代数。影响：`vp_envelope` 的理论线随
之反号（`lndEe` 从衰减变增长），`solve_vlasov_poisson` 的默认输出随之改变；属对外数值
承诺变更，需要物理审核，且第 3 条仍未解释（离散模型为何不含该根）。

**B. 不动行为，只把约定写清楚（当前安全默认）**：docstring 与合同记明 `wi` 的定义
（是 `Im omega` 还是衰减率）、第 2 条的闭式根，并**撤回 "exact root"**，改成"该约定下返回的
参考值，受有限速度窗影响"；第 3 条只作为已知局限写入 `known_limitations`，不写成结论。
依据：零风险，不改变任何数值。影响：读者得到一个与精确根反号、又与离散谱无关的"理论值"，
必须靠文字分辨。

**C. 不返回理论值**：`vp_distribution` 只返回导数，`wr/wi` 一律 `None`，
`vp_envelope` 的 `lndEe` 由调用方给。依据：消除"理论值不可信"的隐患。
影响：签名/返回元组语义变更，`vp_init`、`vp_evolve`、`solve_vlasov_poisson` 链路都要改，
属 API 变更，需要人工批准。

## 各方意见

支持 A 的是它让理论线与第 1、2 条的精确代数一致。反对 A 的是：符号方向属于约定问题，
改它要动 `vp_envelope` 的理论线与 `solve_vlasov_poisson` 的默认输出，属对外数值承诺变更，
需要物理分级评审，而本单目前能核对的只有"约定下的闭式根是什么"，还不足以定"哪一支才是
想要的那一支"。支持 B 的是零风险、并且把可核对的事实（约定、闭式根、诊断是短时拟合）
写在读者能看到的地方；反对 B 的是"the exact root"这一措辞本身与第 2 条不符。C 最干净，
但改动面最大，同样需要人工批准。

## 不决定的后果（已执行的安全默认）

`scirel.kinetic.vp-distribution`、`vp-init`、`vp-landau` 三份合同的 `verification.scope`
已写入 `cannot establish` 段落（并明确"exact root"未建立），说明上报的 `(1, -sqrt(2)k)` 与第 2 条的闭式根符号相反、
无法由 40 位闭式复现，并引用本单；合同**没有**把该值改写成"已建立"，也**没有**把"谱纯实"
当作依据。实现与数值均未改动。

默认建议：选项 B。可核对的事实（文档原文、实现约定、解出的根）已经足够写清楚，而"要不要动
符号、要不要继续返回这一对值"是约定裁决，需要物理分级评审，本单不替它做决定。本轮不主张
"返回的阻尼根是错的物理结论"——主张的是**它没有被证实**。
