开始使用
============

SciRel 将有明确输入、输出和适用条件的科学关系封装为 Python 函数。简单问题可直接调用一个函数；需要多个关系共同完成的计算，可使用复合入口，或在核对科学合同后按顺序组合。

选择能力
------------

先从 :doc:`user-guide/index` 找到要解决的问题，再查阅 :doc:`reference/index` 中的函数说明。不要仅凭函数名判断两个模型可以互换：坐标、单位、归一化、边界条件和失败语义都是调用合同的一部分。

例如，计算圆线圈磁场时，圆环几何与单位电流响应是一个步骤，按实际电流叠加是另一个步骤。矩形截面线圈组则已有组合这两个步骤的公开入口。

安装与版本
------------

使用已取得的精确 SciRel wheel 及其声明的运行依赖。本手册汇集多个开发版本的正式文档，尚不能用一个通用安装命令代表全部已收录能力；也不假设同名开发版本的不同 wheel 字节相同。

取得文件后，可以使用 Python 的标准 wheel 安装方式：

.. code-block:: bash

   python -m venv .venv
   .venv/bin/python -m pip install /实际路径/scirel-具体版本.whl

以上路径为占位示意，应替换为实际取得的文件。科学计算运行时不需要原来源项目、审核数据库或本手册服务。具体包所含能力和依赖应以其交付说明及安装验证为准。

第一个完整案例
------------------

:doc:`tutorials/magnetostatics` 从一个圆电流环开始，展示实际输入、调用代码、数值结果、图表与解析检查，随后扩展到对称线圈对和矩形截面线圈组。页面明确列出案例采用的精确包与依赖版本。

理解结果
------------

函数返回成功并不自动说明物理模型适合当前问题。调用前检查单位、数组轴序与有效域；调用后检查诊断、守恒或对称性、极限关系与网格变化。对于迭代求解，还需读取停止原因与不收敛状态。

函数页中的“示例”保留正式合同提供的代码与预期行为；完整教程中的“运行结果”来自已冻结的实际执行。二者分别陈述，不把文档构建当作新的科学运行。
