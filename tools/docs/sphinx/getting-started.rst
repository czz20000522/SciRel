开始使用
============

SciRel 将有明确输入、输出和适用条件的科学关系封装为 Python 函数。简单问题可直接调用一个函数；需要多个关系共同完成的计算，可以在核对科学合同后把这些函数按顺序组合。

选择能力
------------

先从 :doc:`user-guide/index` 找到要解决的问题，再查阅 :doc:`reference/index` 中的函数说明。不要仅凭函数名判断两个模型可以互换：坐标、单位、归一化、边界条件和失败语义都是调用合同的一部分。

例如，计算圆线圈磁场时，圆环几何与单位电流响应是一个步骤，按实际电流叠加是另一个步骤。矩形截面线圈组则由一个同时组织这两个步骤的公开函数提供。

安装
----

使用所选 SciRel wheel 及其声明的运行依赖。各函数保留自己的来源实现边界；累积包把已接收能力通过同一安装包交付。请按当前文档选集对应的安装说明选择包，并遵循该包的安装和平台说明。

取得文件后，可以使用 Python 的标准 wheel 安装方式：

.. code-block:: bash

   python -m venv .venv
   .venv/bin/python -m pip install /path/to/scirel-wheel.whl

以上路径为占位示意，应替换为实际取得的文件。科学计算运行时不需要原来源项目、审核数据库或本手册服务。具体包所含能力和依赖应以其交付说明及安装验证为准。

按领域导入与计算案例
------------------------

按领域使用子包
~~~~~~~~~~~~~~~~~~

公共能力按科学领域组织，例如磁场计算使用 ``scirel.field``、动力学使用 ``scirel.kinetic``、平衡求解使用 ``scirel.equilibrium``。函数详情中的完整模块路径始终是确切调用依据，学习章节可以将跨子包的相关问题放在一起。

在包含相应能力的安装包中，可以先选择领域，再调用函数：

.. code-block:: python

   from scirel import field

   # 先查阅该函数的参数、单位与边界约定，再构造输入。
   solve_field = field.solve_multi_coil_vacuum_field

此片段演示导入方式，不是一次磁场计算。``import scirel`` 按需加载领域；访问具体能力时才需要它的运行依赖。顶层仅提供领域子包，科学函数通过领域入口或函数页声明的完整模块路径调用。

理解结果
------------

函数返回成功并不自动说明物理模型适合当前问题。调用前检查单位、数组轴序与有效域；调用后检查诊断、守恒或对称性、极限关系与网格变化。对于迭代求解，还需读取停止原因与不收敛状态。

函数页中的“示例”保留正式合同提供的代码与预期行为；完整教程中的“运行结果”来自已冻结的实际执行。二者分别陈述，不把文档构建当作新的科学运行。
